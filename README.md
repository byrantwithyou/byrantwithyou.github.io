# Minimal Light PhD homepage

Based on the remote Jekyll theme `yaoyao-liu/minimal-light`.

Edit `_config.yml` for your name, affiliation, contact and optional links.
Edit `index.md` for research interests and text-only publications.

To publish, create a repository named `YOUR_USERNAME.github.io`, upload these files, and enable GitHub Pages deployment from the main branch (root).

Publication entries are examples, not actual papers.
